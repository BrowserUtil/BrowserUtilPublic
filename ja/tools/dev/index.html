開発ツール

'JSON・Base64・正規表現など開発でよく使う整形・エンコード・変換ツールを、すべてローカルで実行します。

すべて テキスト 開発 画像 日常

6 個のツール

JSON 整形

JSON を見やすく整形・圧縮・検証し、エラー位置を正確に表示します。折りたたみ可能なツリー表示と、このブラウザに保存される最新 5 件の履歴も備えています。

JS オブジェクト JSON 変換

JavaScript / TypeScript オブジェクトリテラルを標準 JSON に瞬時に変換（逆変換にも対応）。引用符なしキー、シングルクォート、コメント、末尾カンマ、整形オプションに対応。

Base64 エンコード / デコード

テキストを Base64 でエンコード・デコードします。UTF-8 セーフモードに対応しています。

タイムスタンプ変換

'Unix タイムスタンプと読みやすい日時を相互に変換します。リアルタイムクロック、タイムゾーン、時間の加減算、コード例も用意しています。

URL エンコード / デコード

URL パーセントエンコードとデコード。コンポーネントモード、完全 URI モード、URL 構造解析に対応。

User-Agent 確認・解析ツール

お使いのブラウザの User-Agent 確認、任意の UA 解析、画面・GPU・ハードウェアスペックの検出、プリセット一覧および各言語のコード生成。

検索に一致するツールはありません。

BrowserUtil について

'開発者と日々の作業のための無料オンラインツール集です。すべてのツールがブラウザ内でローカルに動作します。

トラッキングなし、アップロードなし、アカウント不要。
