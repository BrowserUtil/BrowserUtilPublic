使い方

  1. 1 「エンコード」を選んでテキストを Base64 に変換するか、「デコード」を選んで元のテキストを復元します。
  2. 2 UTF-8 セーフモード、URL セーフ文字（-_）、MIME 改行など、目的に合わせたオプションを設定します。
  3. 3 ワンクリックで結果をコピーしたり、テキストファイルとしてブラウザから保存できます。

主な機能

  • リアルタイム双方向 Base64 エンコード・デコード
  • 日本語、中国語、韓国語、絵文字に対応した UTF-8 セーフモード
  • URL セーフモード（RFC 4648 §5）およびパディング（=）の制御
  • MIME（64 文字）および PEM（76 文字）規格の自動改行
  • Data URL プレフィックスの自動識別と本文デコード
  • 文字数、バイト数、データサイズ変化率のリアルタイム統計
  • 100% ブラウザ内で完结するローカル処理でプライバシーを保護

よくある質問

Base64 エンコードとは何ですか？どのような用途で使われますか？

'Base64 は、バイナリデータを 64 種類の印字可能な ASCII 文字（A-Z、a-z、0-9、+、/）で表現するエンコード方式です。電子メール（MIME）、JSON や API、URL や Cookie で安全にデータを送受信する場面で広く利用されています。

標準 Base64 と URL セーフ Base64 の違いは何ですか？

'標準の Base64 で使われる「+」と「/」は、URL のクエリパラメータやパスで特別な意味を持ちます。URL セーフ Base64（RFC 4648）では「+」を「-」に、「/」を「_」に置き換え、末尾の「=」パディングを省略することで、追加のパーセントエンコードなしで URL や JWT トークン内に直接安全に使用できます。

日本語や絵文字をエンコードするとエラーや文字化けが起きるのはなぜですか？

'ブラウザ標準の window.btoa 関数は Latin-1（0〜255）の範囲にしか対応していません。マルチバイトの日本語や絵文字を渡すと例外が発生します。BrowserUtil は既定で UTF-8 セーフモードを有効にし、標準の UTF-8 バイト列に変換してから処理するため、すべての Unicode 文字を正しく扱えます。

入力したテキストはサーバーに送信されますか？

'いいえ。すべての処理はブラウザ内の JavaScript（TextEncoder、TextDecoder）によって完全にローカルで実行されます。インターネット経由でデータが送信されることはありません。
