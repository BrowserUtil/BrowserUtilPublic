BrowserUtil

ブラウザの中で動く開発・作業効率ツール

'登録もアップロードもサーバー通信も不要です。BrowserUtil のすべてのツールはブラウザのタブ内でローカルに実行されるため、入力したテキストが端末から外に出ることはありません。

無料・アカウント不要 データは端末から出ません オフラインでも動作

ツール

使いたいツールを選んでください。ほかにも準備中です。

13 個のツール

テキスト比較

2 つのテキストや JSON を行単位で比較し、追加・削除・変更をすべて強調表示します。すべてブラウザ内で実行されます。

文字数カウント

'文字数・単語数・行数・段落数・文数と読了時間をリアルタイムに集計します。英語と CJK のテキストに対応しています。

PDF テキスト抽出

ブラウザ内で PDF ドキュメントからテキストをローカル抽出。ページ範囲指定、改行や空白の整形、文字数集計、TXT エクスポートに対応。

JSON 整形

JSON を見やすく整形・圧縮・検証し、エラー位置を正確に表示します。折りたたみ可能なツリー表示と、このブラウザに保存される最新 5 件の履歴も備えています。

JS オブジェクト JSON 変換

JavaScript / TypeScript オブジェクトリテラルを標準 JSON に瞬時に変換（逆変換にも対応）。引用符なしキー、シングルクォート、コメント、末尾カンマ、整形オプションに対応。

Base64 エンコード / デコード

テキストを Base64 でエンコード・デコードします。UTF-8 セーフモードに対応しています。

タイムスタンプ変換

'Unix タイムスタンプと読みやすい日時を相互に変換します。リアルタイムクロック、タイムゾーン、時間の加減算、コード例も用意しています。

URL エンコード / デコード

URL パーセントエンコードとデコード。コンポーネントモード、完全 URI モード、URL 構造解析に対応。

カラー変換

HEX、RGB、HSL、HSV、CMYK の相互変換。カラーピッカー、WCAG コントラスト比判定、明暗パレット付き。

パスワード生成

強固なランダムパスワード、覚えやすいパスフレーズ、数字 PIN をブラウザ内で安全に生成。

2027年中国法定祝日カウントダウン

2027年の中国法定祝日（元日、春節、清明節、メーデー、端午節、中秋節、国慶節）のリアルタイム秒単位カウントダウンと前後カレンダー・振替出勤スケジュール。

猫猫今天喝什么

可爱猫猫奶茶幸运大转盘：自定义录入奶茶品牌、品名与多维标签，一键摇出今日专属饮品，拯救下午茶选择困难症！

User-Agent 確認・解析ツール

お使いのブラウザの User-Agent 確認、任意の UA 解析、画面・GPU・ハードウェアスペックの検出、プリセット一覧および各言語のコード生成。

検索に一致するツールはありません。

BrowserUtil について

'開発者と日々の作業のための無料オンラインツール集です。すべてのツールがブラウザ内でローカルに動作します。

トラッキングなし、アップロードなし、アカウント不要。
