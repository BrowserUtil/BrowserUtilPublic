JSON 整形

'JSON を見やすく整形・圧縮・検証し、エラー位置を正確に表示します。折りたたみ可能なツリー表示と、このブラウザに保存される最新 5 件の履歴も備えています。

使い方

  1. 1 エディタに JSON を貼り付けるか入力します。結果は入力に合わせて更新されます。
  2. 2 インデントを選び、キーの並べ替えや非 ASCII のエスケープを設定します。
  3. 3 整形・圧縮・折りたたみツリー表示を切り替えて確認します。
  4. 4 下のローカル履歴から以前のドキュメントを再度開きます。

主な機能

  • スペース 2 つ・4 つ・タブのインデントとワンクリック圧縮
  • リアルタイム検証とエラー行・列の正確な表示
  • 大きく深くネストしたドキュメントに便利な折りたたみツリー
  • キーの並べ替えと非 ASCII エスケープのオプション
  • ドキュメント統計：文字数、バイト数、深度、ノード数、キー数
  • ブラウザ内だけに保存される最新 5 件の履歴
  • アップロード不要、アカウント不要、解析はすべてブラウザ内で実行

よくある質問

JSON はサーバーにアップロードされますか？

'いいえ。解析と整形はブラウザのタブ内の JavaScript で行われるため、データが端末から外に出ることはありません。

履歴はどこに保存されますか？削除方法は？

'最新 5 件がこのブラウザの localStorage に保存されます。履歴カードから 1 件ずつ削除するか、まとめて消去できます。

コメントや末尾のカンマに対応していますか？

'対応していません。標準の JSON パーサーを使うため、コメント・末尾のカンマ・シングルクォートは先に取り除く必要があります。エラー位置が確認箇所を示します。

キーを並べ替えるとデータは変わりますか？

'出力順が変わるだけで値は変わりません。並べ替えは整形結果にのみ適用され、配列の順序は決して変更されません。
