タイムスタンプ変換

'Unix タイムスタンプと読みやすい日時を相互に変換します。リアルタイムクロック、タイムゾーン、時間の加減算、コード例も用意しています。

現在時刻

毎秒更新され、すべてブラウザのタブ内で計算されます。

タイムスタンプを入力または貼り付けると、すべての形式が一度に表示されます。

日時 → タイムスタンプ

日時を選択すると対応するタイムスタンプが表示されます。

時間の加算・減算

基準時刻を選ぶと計算結果が表示されます。

世界各地の時刻

同じ瞬間を別のタイムゾーンで表示します。

タイムスタンプを入力または貼り付けると、すべての形式が一度に表示されます。

コード例

JavaScript
const date = new Date(1700000000 * 1000)
date.toISOString() // ""
Python
from datetime import datetime, timezone

datetime.fromtimestamp(1700000000, tz=timezone.utc)
# 2023-11-14 22:13:20 UTC
Go
t := time.Unix(1700000000, 0).UTC()
fmt.Println(t.Format(time.RFC3339)) // 2023-11-14T22:13:20Z
PHP
echo date('Y-m-d H:i:s', 1700000000); // 2023-11-14 22:13:20 (UTC)
MySQL
SELECT FROM_UNIXTIME(1700000000); -- 2023-11-14 22:13:20
SELECT UNIX_TIMESTAMP('2023-11-14 22:13:20'); -- 1700000000
Shell
date -r 1700000000          # macOS / BSD
date -d @1700000000         # GNU / Linux
# 2023-11-14 22:13:20 UTC

使い方

  1. 1 上部のリアルタイムクロックを見るか、変換欄にタイムスタンプを貼り付けます。
  2. 2 単位を選びます。自動判定は秒・ミリ秒・マイクロ秒・ナノ秒を判別します。
  3. 3 表示タイムゾーンを選び、ローカル時刻・UTC・ISO 8601・相対時間を確認します。
  4. 4 逆に日時選択で変換したり、任意の瞬間に時間を加減算したりできます。

主な機能

  • 秒・ミリ秒精度のリアルタイムクロック（一時停止・コピー可）
  • 秒・ミリ秒・マイクロ秒・ナノ秒の自動判定
  • ローカル時刻、UTC、ISO 8601、HTTP 日時、詳細形式を同時に表示
  • 表示・入力の両方で任意の IANA タイムゾーンに対応（夏時間を含む）
  • 指定したタイムゾーンで日時をタイムスタンプに変換
  • 時間計算：秒・分・時間・日・週・月・年の加減算
  • 世界時計の表と JS・Python・Go・PHP・MySQL・Shell のコード例
  • 1970 年より前の日付に対応する負のタイムスタンプ
  • アップロード不要、アカウント不要、すべてブラウザ内で実行

よくある質問

タイムスタンプが秒かミリ秒かはどう判断しますか？

'一般的に秒は 10 桁、ミリ秒は 13 桁です。自動判定は桁数で判断し、プルダウンで単位を固定することもできます。

サーバーの出力と結果が違うのはなぜですか？

'サーバーは通常 UTC、ブラウザはローカル時刻を表示します。ここでは両方を表示し、表示タイムゾーンのプルダウンで任意のゾーンに切り替えられます。

1970 年より前の日付も使えますか？

'使えます。JavaScript の Date が扱える範囲であれば、負のタイムスタンプも同じように変換されます。

データはどこかにアップロードされますか？

いいえ。時計・変換・コード例まですべてブラウザの JavaScript で計算されます。
