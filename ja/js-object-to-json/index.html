JavaScript / TypeScript オブジェクトリテラルを標準 JSON に瞬時に変換（逆変換にも対応）。引用符なしキー、シングルクォート、コメント、末尾カンマ、整形オプションに対応。

使い方

  1. 1 左側のエディタに JavaScript オブジェクト、設定コード、または JSON を入力します。
  2. 2 変換モードを選択します：「JS オブジェクト → JSON」または「JSON → JS オブジェクト」。
  3. 3 インデント（2/4 スペース、タブ、圧縮）、キーの並べ替え、クォート形式などを設定します。
  4. 4 ワンクリックで結果をコピー、または .json / .js ファイルとして保存します。

主な機能

  • JS オブジェクトリテラル、配列、変数宣言（const、let、var、export default）を構文解析
  • 引用符なしキー、シングルクォート、バックティック、末尾カンマに対応
  • 1 行コメント（//）および複数行コメント（/* */）を自動除去
  • undefined、NaN、Infinity、BigInt、Date、正規表現、関数の多彩な変換オプション
  • 双方向変換：JS オブジェクト → JSON および JSON → JS オブジェクトコード生成
  • 100% ブラウザ完結 — 高速・安全でプライバシーを保護

よくある質問

JavaScript オブジェクトと JSON の違いは何ですか？

JSON はキーのダブルクォートが必須で、コメント、シングルクォート、末尾カンマ、関数や undefined を許可しない厳格なデータ形式です。対して JavaScript オブジェクトは引用符なしキー、コメント、多彩な型をサポートする柔軟なコード構造です。

console.log の出力や変数宣言コードも変換できますか？

はい！console.log の出力や、'const config = { ... };'、'export default { ... };' などの宣言を含むコードをそのまま貼り付けても自動でオブジェクトを抽出して変換できます。

関数、undefined、Date はどのように変換されますか？

標準の JSON.stringify の仕様に合わせ、デフォルトで関数と undefined は除外されます。設定で null に変換したり、関数を文字列として保持することも可能です。Date は ISO 8601 文字列に変換されます。

入力したデータはサーバーに送信されますか？

いいえ。すべての処理はブラウザ内で完結しており、外部サーバーに送信されることは一切ありません。
