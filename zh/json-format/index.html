常见问题

我的 JSON 会被上传到服务器吗？

不会。解析与格式化都由浏览器里的 JavaScript 完成，数据不会离开你的设备。

历史记录保存在哪里？怎么删除？

最近 5 条记录保存在本浏览器的 localStorage 中。可以在历史卡片里删除单条，或一键清空全部。

支持注释或尾随逗号吗？

不支持。这里使用标准 JSON 解析器，注释、尾随逗号与单引号需要先清理掉，报错位置会告诉你从哪看起。

按键名排序会改变数据吗？

只会改变输出顺序，值本身不变。排序仅作用于格式化结果，数组顺序不会被改动。
