13 个工具

文本对比

逐行对比两段文本或 JSON，高亮所有新增、删除与修改，完全在你的浏览器中完成。

字数统计

实时统计字符数、单词数、行数、段落数、句子数与阅读时长，同时支持英文与中文文本。

PDF 转文字

纯前端本地 PDF 转文字工具。支持指定页面范围、保留换行或段落合并、统计字符与词数，一键导出 TXT 纯文本。

JSON 格式化

美化、压缩并校验 JSON，错误位置一目了然，支持可折叠树形预览与本地保存最近 5 条记录。

JS 对象转 JSON

将 JavaScript / TypeScript 对象字面量快速转换为标准 JSON（并支持逆向转换）。支持未加引号的键名、单引号、注释、尾后逗号及自定义格式化选项。

Base64 编解码

对文本进行 Base64 编码与解码，支持 UTF-8 安全模式。

时间戳转换

在 Unix 时间戳与可读日期之间相互转换，附带实时时钟、时区切换、时间加减与代码示例。

URL 编解码

URL 百分号编码与解码，支持组件编码、完整 URI 模式及 URL 结构解析。

颜色转换

HEX、RGB、HSL、HSV 与 CMYK 颜色互转，集成取色器、对比度检测与明暗色阶。

密码生成器

本地生成高强度随机密码、易记口令短语与数字 PIN 码，安全不上传。

2027年中国法定节假日倒计时

2027年中国法定节假日实时倒计时：提供2027年元旦倒计时、春节倒计时、清明节倒计时、劳动节倒计时、端午节倒计时、中秋节倒计时与国庆节倒计时，实时计算剩余天数与秒数，附国务院官方放假调休安排与前后排班日历。

猫猫今天喝什么

可爱猫猫今天喝什么：自定义录入奶茶与咖啡品牌、品名与多维标签（酸甜、经典咖啡、奶油奶盖、低卡清爽等），卡片轮播飞速滚动，一键摇出今日专属饮品，拯救下午茶与咖啡选择困难症！

User-Agent 查询与解析

查看当前浏览器的 User-Agent，解析任意 UA 字符串，检测屏幕、GPU 与硬件规格，浏览预设库并生成各语言请求代码。
