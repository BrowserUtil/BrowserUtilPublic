9 个工具

文本对比

逐行对比两段文本，高亮所有新增、删除与修改，完全在你的浏览器中完成。

字数统计

实时统计字符数、单词数、行数、段落数、句子数与阅读时长，同时支持英文与中文文本。

JSON 格式化

'美化、压缩并校验 JSON，错误位置一目了然，支持可折叠树形预览与本地保存最近 5 条记录。

Base64 编解码

对文本进行 Base64 编码与解码，支持 UTF-8 安全模式。

时间戳转换

在 Unix 时间戳与可读日期之间相互转换，附带实时时钟、时区切换、时间加减与代码示例。

URL 编解码

URL 百分号编码与解码，支持组件编码、完整 URI 模式及 URL 结构解析。

颜色转换

HEX、RGB、HSL、HSV 与 CMYK 颜色互转，集成取色器、对比度检测与明暗色阶。

密码生成器

本地生成高强度随机密码、易记口令短语与数字 PIN 码，安全不上传。

User-Agent 查询与解析

查看当前浏览器的 User-Agent，解析任意 UA 字符串，检测屏幕、GPU 与硬件规格，浏览预设库并生成各语言请求代码。
