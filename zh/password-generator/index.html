密码生成器

本地生成高强度随机密码、易记口令短语与数字 PIN 码，安全不上传。

强度等级: 极弱0 bits · 估算破解耗时: < 1s
16

使用方法

  1. 1 选择生成模式：经典随机字符、易记单词口令或纯数字 PIN 码。
  2. 2 自由设置密码长度、字符类型组合（大小写、数字、符号）或词语数量。
  3. 3 点击“重新生成”，查看实时的香农信息熵与强度估算。
  4. 4 一键复制密码，或开启批量生成一次性获取多个密码。

功能特点

  • 基于浏览器原生 Web Crypto API 生成真随机数，具备密码学安全性
  • 三种生成模式：高强度字符密码、可读性极佳的口令短语及银行卡级 PIN
  • 实时计算香农信息熵（Entropy Bits）与暴力破解耗时预估
  • 支持排除容易混淆的字符（如 1 与 l、0 与 O）
  • 批量生成模式，支持一键批量复制
  • 会话临时历史记录（仅保存在组件状态中，关闭即焚）
  • 纯本地执行，密码绝不上传至任何服务器

常见问题

浏览器生成的随机密码安全吗？

非常安全。BrowserUtil 使用浏览器原生密码学安全伪随机数生成器（window.crypto.getRandomValues()），其随机熵直接来自操作系统的安全硬件噪声，远比普通 Math.random() 可靠。

什么是口令短语（Passphrase），它有什么优势？

口令短语是由多个随机英文单词组成的密码（例如 crystal-river-brave-falcon）。由于包含多个词汇，信息熵极高，同时便于人类记忆和在移动设备上输入。

生成的密码会被记录在网站服务器上吗？

绝对不会。生成逻辑 100% 在你的浏览器本地完成，没有任何数据包发送到任何服务器或存储在云端。
