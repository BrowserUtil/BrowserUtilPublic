代码示例

JavaScript
const date = new Date(1700000000 * 1000)
date.toISOString() // ""
Python
from datetime import datetime, timezone

datetime.fromtimestamp(1700000000, tz=timezone.utc)
# 2023-11-14 22:13:20 UTC
Go
t := time.Unix(1700000000, 0).UTC()
fmt.Println(t.Format(time.RFC3339)) // 2023-11-14T22:13:20Z
PHP
echo date('Y-m-d H:i:s', 1700000000); // 2023-11-14 22:13:20 (UTC)
MySQL
SELECT FROM_UNIXTIME(1700000000); -- 2023-11-14 22:13:20
SELECT UNIX_TIMESTAMP('2023-11-14 22:13:20'); -- 1700000000
Shell
date -r 1700000000          # macOS / BSD
date -d @1700000000         # GNU / Linux
# 2023-11-14 22:13:20 UTC

使用方法

  1. 1 查看顶部实时时钟，或把时间戳粘贴进转换框。
  2. 2 选择单位——自动识别可区分秒、毫秒、微秒与纳秒。
  3. 3 选择显示时区，即可同时看到本地时间、UTC 时间、ISO 8601 与相对时间。
  4. 4 也可以反过来用日期选择器换算，或对任意时刻做时间加减。

常见问题

怎么判断时间戳是秒还是毫秒？

秒级通常是 10 位，毫秒级通常是 13 位。自动识别按位数判断，你也可以用下拉框强制指定单位。

为什么结果和服务器打印的不一样？

服务器通常输出 UTC，而浏览器默认显示本地时间。这里两者都会给出，也可以用显示时区下拉框切换到任意时区。

支持 1970 年之前的日期吗？

支持。负时间戳同样可以正常换算，只要不超过 JavaScript 日期可表示的范围。

我的数据会被上传吗？

不会。时钟、换算与代码示例都由浏览器里的 JavaScript 完成。
