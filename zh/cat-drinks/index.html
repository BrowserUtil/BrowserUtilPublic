常见问题

筛选标签后，候选卡片会改变吗？

会！只要点击上方的口味、奶茶或咖啡标签，轮播卡池就会立即动态过滤，仅保留符合条件的饮品，绝对不会抽到不符合要求的饮品。

我录入的自创奶茶或私藏咖啡会丢失吗？

不会。所有录入的饮品均自动保存在当前浏览器的 LocalStorage 中，即使刷新或重新打开网页依然保留。您也可以在管理面板中一键导出 JSON 文件妥善备份。

卡片滚动时的音效如何开启或关闭？

右上角配有显眼的“🔊 喵喵音效”开关按钮，卡片切换时的齿轮咔嗒声与猫叫声均采用浏览器 Web Audio API 实时合成，点击按钮即可随时一键静音。

可以把我和朋友常喝的饮单分享给好友吗？

可以！在饮品库管理界面中点击“导出配置”，将生成的 JSON 文本或文件发送给朋友，朋友在自己的电脑或手机上点击“导入配置”即可直接同步。

页面中的品牌名称和风味文案是品牌官方提供的吗？

不是。本工具为纯前端个人生活决策辅助工具，所提及的茶饮与咖啡品牌名称、商品名称其商标权及知识产权均归各品牌方所有。饮品风味笔记、推荐搭配与评语系结合网络公开资料、大众饮客品尝心得及 AI 整理生成的主观速记体验，非各品牌官方宣传文案或官方标准配方，本站与各品牌无商业隶属、合作或赞助关系。

页面标注的饮品价格准确吗？

标注价格仅供参考。由于不同城市分店、商圈租金、堂食与外卖平台活动及季节限定调整，实际价格、杯型规格及配料请以您前往的各品牌实体门店或官方小程序现场结算为准。
