常见问题

JSON 和 YAML 有什么区别？

JSON 格式严谨，键名必须加双引号，且不允许注释和尾随逗号；YAML 依靠缩进排版，更加简洁易读，支持行内注释。本工具支持两者毫秒级双向无损互转。

能否将 JavaScript 对象代码直接转为 YAML？

支持！只需打开工具栏的“支持 JS 对象”开关，即可直接粘贴包含无引号键名、单引号、尾随逗号、注释或 const/export 变量声明的原生 JavaScript 代码，一键转为 YAML；从 YAML 也可以直接输出规范的 JS 对象代码。

如何对 YAML 代码进行格式化与校验？

可以！输入 YAML 时页面会自动进行实时语法校验；点击工具栏的“格式化”按钮，即可就地规范化缩进（2 或 4 格）与排版美化。

我的数据会上传到服务器吗？

完全不会。所有解析与转换均在您本地浏览器中基于 js-yaml 完成，数据绝不上传服务器，保障隐私安全。
