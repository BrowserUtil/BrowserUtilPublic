使用方法

  1. 1 选择“编码”对文本或网址进行百分号编码，或选择“解码”还原原始字符。
  2. 2 在组件模式（encodeURIComponent）与完整 URL 模式（encodeURI）之间切换。
  3. 3 切换到“URL 深度解析”可将任何网址自动拆解为协议、域名、路径及查询参数表格。

功能特点

  • 实时双向 URL 编码与解码

  • 支持将空格编码为 +（application/x-www-form-urlencoded 标准）

  • URL 结构解析器，清晰展示各层级路径与 Query 查询参数表格

  • 100% 浏览器本地运算，数据不经过任何服务器

常见问题

encodeURI 与 encodeURIComponent 有什么区别？

encodeURI 用于编码整个网址，会保留协议分界符如“http://”、“/”、“?”和“&”；而 encodeURIComponent 会对所有特殊字符编码，专用于查询参数的值，防止参数破坏整体 URL 结构。

为什么空格有时被编码为 %20，有时被编码为 +？

%20 是 URI 规范 RFC 3986 的标准百分号编码；加号（+）则是 HTML 表单提交（application/x-www-form-urlencoded）的历史标准。BrowserUtil 支持一键切换这两种格式。

我的 URL 或私密 Token 会被上传吗？

绝不会。所有解析与编解码全部在当前浏览器选项卡内由 JavaScript 本地完成，不发生任何网络请求。
