使用方法

  1. 1 选择“编码”将文本转为 Base64，或选择“解码”还原原始文本内容。
  2. 2 根据需求开启 UTF-8 安全模式、URL 安全字符（-_）或按 MIME 规范每 64 字符自动换行。
  3. 3 一键复制结果，或直接在浏览器中下载保存为文本文件。

常见问题

什么是 Base64 编码？主要用于哪些场景？

'Base64 是一种用 64 个可打印字符（A-Z、a-z、0-9、+、/）来表示二进制数据的编码方式。常用于在电子邮件协议（MIME）中传输数据，或在 JSON 与 API 请求、URL、Cookie 中传递数据避免编码冲突。

标准 Base64 与 URL 安全 Base64 有何区别？

'标准 Base64 使用 "+" 和 "/"，这两个符号在 URL 查询参数或路径中有特殊含义。URL 安全 Base64（RFC 4648）将 "+" 替换为 "-"、将 "/" 替换为 "_"，并且通常省略尾部的 "=" 填充符，可直接放入 URL、Cookie 或 JWT Token 中而无需额外进行 URL 编码。

为什么有些工具在编码中文或 Emoji 时会乱码或报错？

'浏览器的原生 window.btoa 函数仅支持 Latin-1 单字节字符范围（0-255）。遇到多字节的中文或 Emoji 表情时会直接抛出异常。BrowserUtil 默认启用 UTF-8 安全模式，先将字符转换为标准的 UTF-8 字节序列再进行编码，确保所有 Unicode 字符均能准确编解码。

我输入的文本会被上传到服务器吗？

'不会。所有编解码均在你的浏览器本地借助 TextEncoder 和 TextDecoder 完成，不会向任何服务器发送数据。
