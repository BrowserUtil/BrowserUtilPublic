使用方法

  1. 1 在左侧输入框中粘贴或输入 JavaScript 对象字面量、配置代码或 JSON 文本。
  2. 2 选择转换模式：“JS 对象 → JSON”或“JSON → JS 对象”。

常见问题

JS 对象和 JSON 有什么区别？

JSON 是一种严格的数据交换规范，键名必须用双引号包裹，禁止使用单引号、注释和尾后逗号，且不支持函数与 undefined。JavaScript 对象字面量是语法更加宽松的代码结构，支持未加引号的键名、单引号、模板字符串、行内/块注释、尾后逗号及丰富的运行时类型。

支持直接粘贴 console.log 输出或变量声明代码吗？

可以！本工具支持解析从 console.log 打印内容、代码文件复制的对象，甚至包含变量前缀的代码（例如 const config = { ... }; 或 export default { ... };），会自动提取有效对象并转换。

如何处理函数、undefined 和 Date 对象？

在转 JSON 模式下，默认遵循标准 JSON.stringify 行为自动忽略函数和 undefined，您也可以设置将其转换为 null 或将函数体转换为字符串。Date 对象会自动转换为 ISO 8601 标准时间字符串。

输入的数据会被上传到服务器吗？

完全不会。所有解析与转换逻辑全部在您的浏览器前端本地执行，没有任何数据会被上传至服务器。
