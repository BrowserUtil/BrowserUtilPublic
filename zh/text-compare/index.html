使用方法

  1. 1 在左侧粘贴原始文本，在右侧粘贴修改后的文本。
  2. 2 当格式不重要时，可开启忽略大小写或忽略空白。
  3. 3 查看高亮结果：绿色为新增，红色为删除，琥珀色为修改。

功能特点

  • 逐行对比并对齐行号
  • 并排与合并两种视图
  • 修改行内按字符级高亮差异
  • 支持忽略大小写、忽略空白与去除首尾空格
  • 给出相似度以及新增、删除、修改行数
  • 全部在本地计算，不会上传任何内容

常见问题

我的文本会被上传到服务器吗？

不会。对比过程完全在你的浏览器中用 JavaScript 完成，文本不会离开你的设备。

相似度是怎么计算的？

它比较相同行数与两侧总行数的比例，因此两段完全一致的文本相似度为 100%。

有大小限制吗？

为保证页面流畅，过大的输入会只取前几千行参与对比。超大文件建议分段处理。
