常见问题

什么是 User-Agent？

User-Agent（用户代理）是浏览器向服务器发送 HTTP 请求时携带的标识头，用以说明当前浏览器的名称、版本号、操作系统及排版引擎，网站常据此提供适配的页面与功能。

什么是 Client Hints（Sec-CH-UA）？

Client Hints 是现代浏览器推行的新一代客户端提示标准，旨在替代日渐臃肿且易导致指纹追踪的传统 User-Agent。Chromium 浏览器会按需发送结构化的 Sec-CH-UA 系列请求头。

我的 User-Agent 或设备数据会被上传吗？

完全不会。BrowserUtil 为纯前端静态工具站，所有解析与参数检测均在本地浏览器内完成，没有任何后端收集或上传你的任何数据。

如何修改或伪造 User-Agent？

你可以在 Chrome / Edge 开发者工具中（F12 -> 更多工具 -> 网络状况 / Network Conditions）临时覆盖 User-Agent，或在爬虫与自动化测试中直接设置请求头，详见本页「代码示例」标签。
