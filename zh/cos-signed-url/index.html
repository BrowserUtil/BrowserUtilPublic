腾讯云 COS 签名链接解析

在浏览器本地解析腾讯云 COS V5 签名链接：解读 q-sign-algorithm、q-ak、q-sign-time、q-key-time 与 q-signature，检查签名是否过期，并查看存储桶与文件信息。

粘贴腾讯云 COS 签名链接，即可查看签名参数、存储桶信息与过期时间。

链接仅在浏览器本地解析，不会上传。请不要粘贴仍在生产环境有效的签名链接——拿到完整链接的人即可访问该文件。

使用方法

  1. 1 粘贴带有 q-sign-* 参数的 COS 签名链接，或点击「加载示例」。
  2. 2 在概览区查看存储桶、地域、文件路径和实时有效期状态。
  3. 3 在下方的表格中查看每个参数的含义，以及解码后的起止时间。
  4. 4 点击「重置」即可把表单恢复为默认的空白状态。

功能特点

  • 识别 COS V5 签名，逐一解释七个 q-* 参数
  • 自动还原 %3B，把 Unix 时间戳换算成本地时间与 UTC
  • 每秒刷新的实时状态：有效、尚未生效或已过期
  • 从标准 COS 域名中解析存储桶、APPID、地域与文件路径
  • 列出签名覆盖的请求头与查询参数
  • 自定义域名只要带有 COS V5 参数同样可以解析
  • 100% 本地运行，不上传任何数据

常见问题

COS 链接里的 q-* 参数是什么？

COS V5 会在签名链接上附加若干 q-* 查询参数，用来说明签名算法、调用方身份、有效期，以及签名覆盖了哪些请求头和查询参数。

为什么 q-sign-algorithm 是 sha1？

sha1 指的是 HMAC-SHA1，是 COS V5 签名规范中唯一定义的算法。这是协议规定，并不是生成链接的应用自己选择的。

链接里会泄露我的 SecretKey 吗？

q-ak 是调用方的 SecretId，用于在请求中标明身份，不是密钥本身。SecretKey 绝不会出现在 URL 中。不过签名链接相当于持有凭证，过期前请不要随意转发。

q-sign-time 和 q-key-time 有什么区别？

q-sign-time 是当前签名的有效期；q-key-time 是生成签名时所用临时密钥的有效期，使用永久密钥时两者通常一致。二者都采用 Unix 秒级时间戳的 start;end 格式。

链接已经过期，这个工具能续期吗？

只有持有 SecretKey 的一方（通常是你的服务端通过 COS SDK）才能生成新的有效签名。本工具只在本地读取链接，无法延长、重算或伪造签名。

我的链接会被上传吗？

可以。解析完全由浏览器标签页中的 JavaScript 完成，链接不会被上传，也不会被保存。
