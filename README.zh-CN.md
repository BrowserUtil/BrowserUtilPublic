# BrowserUtil

**在你的浏览器里运行的在线开发者与效率工具**

[English](README.md) · [简体中文](README.zh-CN.md)

🌐 <https://browserutil.com> · 🇨🇳 中文版：<https://browserutil.com/zh/>

BrowserUtil 是一组小而专的在线工具集合，面向开发者和日常办公场景——文本对比、字数统计、格式化、
编码转换等等。所有工具都**完全在你的浏览器标签页中运行**：无需注册、无需上传、不经过任何服务器。

---

## 为什么选择 BrowserUtil

| | |
| --- | --- |
| 🔒 **隐私优先** | 全部计算都在本地用 JavaScript 完成，你输入的内容和文件不会离开你的设备。 |
| 🆓 **免费、无需账号** | 打开页面就能用，没有登录、没有配额、没有付费墙。 |
| ⚡ **即时响应** | 输入即出结果，对比与统计都在本地完成，没有网络延迟。 |
| 📴 **可离线使用** | 页面加载完成后，断网也能继续工作。 |
| 🌏 **中英双语** | 完整的英文与简体中文界面，每种语言都有独立的 URL、canonical 与 hreflang 标注。 |
| 📦 **零安装** | 不需要下载或配置任何东西，它只是一个静态站点。 |

## 隐私说明

BrowserUtil 没有处理工具输入的后端：不会对你的内容做任何统计，使用工具也不需要 Cookie，
粘贴的内容不会发往任何地方。唯一的本地存储是 `localStorage['browserutil-lang']`，用于记住
你选择的语言。

## 关于本仓库

本仓库存放的是 BrowserUtil 的**构建产物**（`dist/`），通过 GitHub Pages 发布并运行在
<https://browserutil.com>。它由 CI 在源码仓库（`BrowserUtil/BrowserUtil`）每次推送 `main` 时
自动生成，请勿手动修改这里的文件，下一次部署会覆盖你的改动。

发现工具有问题，或想推荐一个新工具？欢迎在本仓库提 issue。
