Frequently asked questions

What is Base64 encoding and why is it used?

'Base64 is a binary-to-text encoding scheme that represents binary data in an ASCII string format using 64 printable characters (A-Z, a-z, 0-9, +, /). It is commonly used to transmit data over text-only protocols like email (MIME), or safely pass text and binary payloads in JSON, URLs, and cookies without encoding issues.

What is the difference between standard and URL-safe Base64?

'Standard Base64 uses "+" and "/", which have special meanings in URL query parameters and filenames. URL-safe Base64 (RFC 4648) replaces "+" with "-" and "/" with "_", and often omits trailing "=" padding, making it safe to use directly inside URLs and web tokens without extra percent-encoding.

Why do non-English characters or emojis sometimes break in Base64?

'JavaScript native window.btoa only accepts Latin-1 characters (0-255). Passing multi-byte Unicode characters like Chinese, Japanese, Korean, or emojis throws an error in basic tools. BrowserUtil enables UTF-8 safe mode by default, converting text into standard UTF-8 byte sequences so all Unicode characters encode and decode accurately.

Is my input data sent to any server?

'No. Everything is processed directly inside your browser tab using JavaScript TextEncoder and TextDecoder. Nothing is transmitted over the internet.
