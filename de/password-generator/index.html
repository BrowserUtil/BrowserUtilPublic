Passwort-Generator

Starke Zufallspasswörter, merkbare Passphrasen und PIN-Codes sicher lokal im Browser generieren.

Stärke: Sehr schwach0 bits · Knackzeit: < 1s
16

Anleitung

  1. 1 Wählen Sie den Modus: Zufällige Zeichen, merkbare Passphrase oder numerische PIN.
  2. 2 Passen Sie Länge, Zeichensätze oder Wortanzahl an.
  3. 3 Klicken Sie auf Generieren und prüfen Sie die Entropie- und Sicherheitsbewertung.
  4. 4 Kopieren Sie das Passwort mit einem Klick oder erstellen Sie mehrere Passwörter auf einmal.

Funktionen

  • Kryptografisch sichere Zufallswerte über die Browser Web Crypto API
  • 3 Modi: anpassbare Zufallszeichen, lesbare Passphrasen und Zahlen-PINs
  • Shannon-Entropieberechnung und Schätzung der Zeit für Brute-Force-Angriffe
  • Option zum Ausschluss leicht verwechselbarer Zeichen (1, l, I, 0, O)
  • Stapelgenerierung mit Ein-Klick-Kopieren aller Passwörter
  • Sitzungsverlauf im Arbeitsspeicher des Tabs (keine Speicherung auf der Festplatte)
  • 100 % clientseitige Ausführung – Passwörter verlassen das Gerät nie

Häufig gestellte Fragen

Wie sicher sind im Browser generierte Passwörter?

Sehr sicher. BrowserUtil nutzt window.crypto.getRandomValues(), den kryptografisch sicheren Zufallszahlengenerator des Betriebssystems, anstelle von gewöhnlichem Math.random().

Was ist eine Passphrase und welche Vorteile hat sie?

Eine Passphrase kombiniert mehrere zufällige Wörter (z. B. crystal-river-brave-falcon). Sie bietet hohe Entropie und lässt sich viel leichter merken und auf Mobilgeräten tippen.

Werden generierte Passwörter irgendwo gespeichert?

Nein. Passwörter existieren nur im flüchtigen Speicher des aktuellen Browser-Tabs und werden niemals übertragen.
