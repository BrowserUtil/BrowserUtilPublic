Häufig gestellte Fragen

Was ist ein User-Agent?

Ein User-Agent ist ein HTTP-Header, den Ihr Browser an Webserver sendet, um Software, Version, Betriebssystem und Rendering-Engine mitzuteilen.

Was sind Client Hints (Sec-CH-UA)?

Client Hints sind ein moderner Webstandard, der herkömmliche User-Agents durch strukturierte, datenschutzfreundliche Header ersetzt.

Werden meine Browserdaten an einen Server übertragen?

Nein. Alle Prüfungen und Analysen laufen ausschließlich lokal über JavaScript in Ihrem Browser ab.

Wie kann ich meinen User-Agent ändern?

In den Entwicklertools (DevTools) von Chrome oder Edge unter 'Network Conditions' oder programmgesteuert in cURL, Python oder Playwright.
