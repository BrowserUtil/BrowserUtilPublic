Code snippets

JavaScript
const date = new Date(1700000000 * 1000)
date.toISOString() // ""
Python
from datetime import datetime, timezone

datetime.fromtimestamp(1700000000, tz=timezone.utc)
# 2023-11-14 22:13:20 UTC
Go
t := time.Unix(1700000000, 0).UTC()
fmt.Println(t.Format(time.RFC3339)) // 2023-11-14T22:13:20Z
PHP
echo date('Y-m-d H:i:s', 1700000000); // 2023-11-14 22:13:20 (UTC)
MySQL
SELECT FROM_UNIXTIME(1700000000); -- 2023-11-14 22:13:20
SELECT UNIX_TIMESTAMP('2023-11-14 22:13:20'); -- 1700000000
Shell
date -r 1700000000          # macOS / BSD
date -d @1700000000         # GNU / Linux
# 2023-11-14 22:13:20 UTC

How to use

  1. 1 Read the live clock at the top, or paste a timestamp into the converter.
  2. 2 Pick the unit — auto detect recognises seconds, milliseconds, microseconds and nanoseconds.
  3. 3 Choose a display time zone and read the local time, UTC time, ISO 8601 and relative time.
  4. 4 Use the date picker the other way round, or add and subtract time from any instant.

Features

  • Live clock with second and millisecond precision, pausable and copyable

Frequently asked questions

How do I know whether a timestamp is in seconds or milliseconds?

'Seconds are usually 10 digits and milliseconds 13. Auto detect uses the number of digits, and you can always force a unit with the dropdown.

Why is the result different from what my server prints?

'Servers usually print UTC while your browser shows local time. Both are shown side by side, and the display time zone dropdown lets you switch to any zone.

Are dates before 1970 supported?

'Yes. Negative timestamps are accepted and converted like any other value, as long as they stay within the range JavaScript dates support.

Is my data uploaded anywhere?

No. The clock, conversions and snippets are all computed with JavaScript inside your browser tab.
