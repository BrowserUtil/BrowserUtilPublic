JS 객체를 JSON으로 변환

JavaScript / TypeScript 객체 리터럴을 표준 JSON으로 변환합니다 (역변환 지원). 따옴표 없는 키, 작은따옴표, 주석, 후행 쉼표 및 다양한 포맷 옵션을 지원합니다.

사용 방법

  1. 1 왼쪽 에디터에 JavaScript 객체 리터럴, 설정 코드 또는 JSON을 붙여넣습니다.
  2. 2 변환 모드를 선택합니다: 'JS 객체 → JSON' 또는 'JSON → JS 객체'.
  3. 3 들여쓰기(2/4 공백, 탭, 압축), 키 정렬, 따옴표 스타일 등을 설정합니다.
  4. 4 원클릭으로 결과를 클립보드에 복사하거나 .json 또는 .js 파일로 다운로드합니다.

주요 기능

  • JS 객체 리터럴, 배열 및 변수 선언(const, let, var, export default) 파싱
  • 따옴표 없는 키, 작은따옴표, 백틱 템플릿, 후행 쉼표 지원
  • 한 줄(//) 및 여러 줄(/* */) 주석 자동 정리
  • undefined, NaN, Infinity, BigInt, Date, 정규식, 함수 지원
  • 양방향 변환: JS 객체 → JSON 및 JSON → JS 객체 역변환
  • 100% 브라우저 로컬 실행으로 안전하고 빠른 개인정보 보호

자주 묻는 질문

JavaScript 객체와 JSON의 차이점은 무엇인가요?

JSON은 키에 큰따옴표를 필수로 요구하며 주석, 작은따옴표, 후행 쉼표, 함수 및 undefined를 허용하지 않는 엄격한 데이터 형식입니다. 반면 JavaScript 객체 리터럴은 유연한 문법으로 주석, 작은따옴표, 다양한 데이터 타입을 지원합니다.

console.log 출력이나 변수 선언 코드도 변환할 수 있나요?

네! console.log 출력이나 'const config = { ... };', 'export default { ... };'와 같은 변환 코드를 그대로 붙여넣어도 자동으로 객체를 추출하여 변환합니다.

함수, undefined, Date는 어떻게 처리되나요?

기본적으로 JSON 표준에 따라 함수와 undefined는 생략되며, 옵션을 통해 null로 변환하거나 함수를 문자열로 유지할 수 있습니다. Date 객체는 ISO 8601 문자열로 변환됩니다.

데이터가 서버로 전송되나요?

아닙니다. 모든 파싱과 변환은 브라우저 내에서 로컬로 실행되며 서버로 데이터를 전송하지 않습니다.
