모든 도구

BrowserUtil의 모든 도구를 카테고리별로 모았습니다.

전체 텍스트 개발 이미지 생활

도구 13개

텍스트 비교

두 텍스트나 JSON을 줄 단위로 비교해 추가·삭제·변경된 부분을 모두 강조 표시합니다. 전부 브라우저에서 실행됩니다.

글자 수 세기

'문자 수, 단어 수, 줄 수, 문단 수, 문장 수와 읽는 시간을 실시간으로 집계합니다. 영어와 CJK 텍스트를 모두 지원합니다.

PDF 텍스트 추출

브라우저에서 PDF 문서의 텍스트를 로컬로 추출합니다. 페이지 범위 선택, 서식 정리, 글자 수 집계 및 TXT 파일 내보내기 지원.

JSON 포맷터

JSON을 보기 좋게 정렬하고 압축·검증하며 오류 위치를 정확히 알려 줍니다. 접을 수 있는 트리 보기와 최근 5개 문서의 로컬 기록도 제공합니다.

JS 객체를 JSON으로 변환

JavaScript / TypeScript 객체 리터럴을 표준 JSON으로 변환합니다 (역변환 지원). 따옴표 없는 키, 작은따옴표, 주석, 후행 쉼표 및 다양한 포맷 옵션을 지원합니다.

Base64 인코딩 / 디코딩

텍스트를 Base64로 인코딩하고 디코딩합니다. UTF-8 안전 모드를 지원합니다.

타임스탬프 변환기

'Unix 타임스탬프와 사람이 읽는 날짜를 서로 변환하고, 실시간 시계·시간대·시간 계산·코드 스니펫을 함께 제공합니다.

URL 인코딩 / 디코딩

URL 퍼센트 인코딩 및 디코딩, 컴포넌트 모드, 전체 URI 모드 및 URL 구조 분석.

색상 변환기

HEX, RGB, HSL, HSV, CMYK 간의 상호 변환, 컬러 피커 및 WCAG 명암비 검사.

비밀번호 생성기

강력한 무작위 비밀번호, 기억하기 쉬운 패스프레이즈 및 PIN 번호를 로컬에서 안전하게 생성.

2027년 중국 법정 공휴일 카운트다운

2027년 중국 법정 공휴일(신정, 설날, 청명절, 노동절, 단오절, 추석, 국경절) 실시간 초 단위 카운트다운 및 대체 휴일·근무일 배정 달력 안내.

猫猫今天喝什么

可爱猫猫奶茶幸运大转盘：自定义录入奶茶品牌、品名与多维标签，一键摇出今日专属饮品，拯救下午茶选择困难症！

User-Agent 확인 및 분석

현재 브라우저의 User-Agent를 확인하고, 임의의 UA 문자열을 파싱하며, 화면·GPU·하드웨어 사양을 감지하고 코드 스니펫을 생성합니다.
