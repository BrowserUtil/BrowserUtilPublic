타임스탬프 변환기

'Unix 타임스탬프와 사람이 읽는 날짜를 서로 변환하고, 실시간 시계·시간대·시간 계산·코드 스니펫을 함께 제공합니다.

현재 시간

매초 갱신되며 모두 브라우저 탭에서 계산됩니다.

초

—

밀리초

—

—

타임스탬프 → 날짜

타임스탬프를 입력하거나 붙여넣으면 모든 형식을 한 번에 볼 수 있습니다.

날짜 → 타임스탬프

날짜와 시간을 선택하면 해당 타임스탬프가 나옵니다.

시간 더하기 / 빼기

기준 시각을 선택하면 계산 결과가 표시됩니다.

세계 시간

같은 순간을 다른 시간대로 표시합니다.

타임스탬프를 입력하거나 붙여넣으면 모든 형식을 한 번에 볼 수 있습니다.

코드 스니펫

JavaScript
const date = new Date(1700000000 * 1000)
date.toISOString() // ""
Python
from datetime import datetime, timezone

datetime.fromtimestamp(1700000000, tz=timezone.utc)
# 2023-11-14 22:13:20 UTC
Go
t := time.Unix(1700000000, 0).UTC()
fmt.Println(t.Format(time.RFC3339)) // 2023-11-14T22:13:20Z
PHP
echo date('Y-m-d H:i:s', 1700000000); // 2023-11-14 22:13:20 (UTC)
MySQL
SELECT FROM_UNIXTIME(1700000000); -- 2023-11-14 22:13:20
SELECT UNIX_TIMESTAMP('2023-11-14 22:13:20'); -- 1700000000
Shell
date -r 1700000000          # macOS / BSD
date -d @1700000000         # GNU / Linux
# 2023-11-14 22:13:20 UTC

사용 방법

  1. 1 맨 위의 실시간 시계를 보거나 변환기에 타임스탬프를 붙여넣으세요.
  2. 2 단위를 선택하세요. 자동 감지는 초·밀리초·마이크로초·나노초를 구분합니다.
  3. 3 표시 시간대를 고르고 로컬 시간, UTC, ISO 8601, 상대 시간을 확인하세요.
  4. 4 반대로 날짜 선택기를 쓰거나 원하는 순간에 시간을 더하고 빼 보세요.

주요 기능

  • 초·밀리초 정밀도의 실시간 시계, 일시정지와 복사 지원
  • 초·밀리초·마이크로초·나노초 타임스탬프 자동 감지
  • 로컬 시간, UTC, ISO 8601, HTTP 날짜, 긴 형식을 한 번에 제공
  • 표시와 입력 모두 임의의 IANA 시간대 지원(서머타임 포함)
  • 원하는 시간대 기준으로 날짜를 타임스탬프로 변환
  • 시간 계산: 초·일·개월·년 단위로 더하고 빼기
  • 세계 시계 표와 JS·Python·Go·PHP·MySQL·Shell 스니펫
  • 1970년 이전 날짜를 위한 음수 타임스탬프 지원
  • 업로드 없음, 계정 불필요, 모든 계산이 브라우저에서 실행

자주 묻는 질문

타임스탬프가 초 단위인지 밀리초 단위인지 어떻게 알 수 있나요?

'보통 초는 10자리, 밀리초는 13자리입니다. 자동 감지는 자릿수를 기준으로 판단하며, 드롭다운에서 단위를 직접 지정할 수도 있습니다.

왜 서버에서 출력한 값과 다른가요?

'서버는 보통 UTC를 출력하고 브라우저는 로컬 시간을 보여 줍니다. 여기서는 둘을 함께 표시하며, 표시 시간대 드롭다운으로 원하는 시간대로 바꿀 수 있습니다.

1970년 이전 날짜도 지원하나요?

'지원합니다. JavaScript Date가 표현할 수 있는 범위 안이라면 음수 타임스탬프도 같은 방식으로 변환됩니다.

내 데이터가 어딘가로 업로드되나요?

아니요. 시계, 변환, 스니펫까지 모두 브라우저 탭의 JavaScript로 계산됩니다.
