사용 방법

  1. 1 변환 방향을 선택합니다: JSON → YAML 또는 YAML → JSON (⇄ 버튼으로 맞바꾸기 가능).
  2. 2 왼쪽 편집기에 코드를 입력하면 오른쪽에 실시간으로 변환 결과가 표시됩니다.
  3. 3 JavaScript 객체나 주석이 포함된 코드를 변환하려면 'JS 객체 지원' 스위치를 켭니다.
  4. 4 YAML 입력 시 실시간 검증 상태를 확인하거나 '코드 정렬' 버튼을 눌러 정돈합니다.

주요 기능

  • JSON과 YAML 간 실시간 양방향 상호 변환 (⇄ 원클릭 방향 전환 지원)
  • 정확한 구문 오류 위치 감지, 줄 번호 거터 빨간색 경고 및 원클릭 '오류로 이동'
  • 따옴표 없는 키, 작은따옴표, 주석이 포함된 JS 코드를 완벽 지원하는 'JS 객체 지원' 모드
  • YAML 제자리 정렬 및 실시간 유효성 검사 (2/4칸 들여쓰기 및 키 정렬 지원)
  • js-yaml (MIT 라이선스) 기반 순수 브라우저 로컬 실행, 문서 통계 및 로컬 기록 제공

자주 묻는 질문

JSON과 YAML의 차이점은 무엇인가요?

JSON은 키에 큰따옴표를 필수로 사용하며 주석과 후행 쉼표를 허용하지 않습니다. YAML은 들여쓰기 기반으로 가독성이 뛰어나며 주석을 지원합니다. 이 도구는 둘 사이를 실시간으로 완벽하게 상호 변환합니다.

JavaScript 객체 리터럴을 YAML로 변환할 수 있나요?

네! 툴바의 'JS 객체 지원' 스위치를 켜면 따옴표 없는 키, 작은따옴표, 주석, 후행 쉼표 및 const/export 선언이 포함된 JavaScript 객체 코드를 직접 YAML로 변환할 수 있습니다.

YAML 코드를 정렬하고 검증하려면 어떻게 하나요?

네! YAML을 입력할 때 자동으로 실시간 유효성 검사가 실행됩니다. 툴바의 '포맷' 버튼을 클릭하면 2칸/4칸 들여쓰기로 즉시 제자리 정렬됩니다.

내 데이터가 서버로 전송되나요?

아니요. 모든 작업은 브라우저 내에서 js-yaml 라이브러리로 100% 로컬 처리되며 데이터가 외부로 전송되지 않습니다.
