JSON 포맷터

'JSON을 보기 좋게 정렬하고 압축·검증하며 오류 위치를 정확히 알려 줍니다. 접을 수 있는 트리 보기와 최근 5개 문서의 로컬 기록도 제공합니다.

JSON 입력

들여쓰기

JSON을 붙여넣으면 포맷이 시작됩니다.

포맷된 JSON이 여기에 표시됩니다.

문서 통계

포맷된 JSON이 여기에 표시됩니다.

최근 문서(이 브라우저에만 저장)

최근 5개의 문서가 브라우저 저장소에 보관되며 업로드되지 않습니다.

아직 저장된 항목이 없습니다. 포맷한 문서가 여기에 표시됩니다.

사용 방법

  1. 1 편집기에 JSON을 붙여넣거나 입력하세요. 입력에 따라 결과가 바로 갱신됩니다.
  2. 2 들여쓰기를 고르고, 키를 정렬하거나 비ASCII 문자를 이스케이프하세요.
  3. 3 보기 좋게·압축·접을 수 있는 트리 보기를 전환해 확인하세요.
  4. 4 아래 로컬 기록에서 이전 문서를 다시 열어 보세요.

주요 기능

  • 스페이스 2칸·4칸·탭 들여쓰기와 원클릭 압축
  • 오류가 난 정확한 행과 열을 실시간으로 표시
  • 크거나 깊게 중첩된 문서를 위한 접을 수 있는 트리 미리보기
  • 키 정렬과 비ASCII 이스케이프 옵션
  • 문서 통계: 문자 수, 바이트, 깊이, 노드 수, 키 수
  • 이 브라우저에만 보관되는 최근 5개 문서 기록
  • 업로드 없음, 계정 불필요, 파싱은 전부 브라우저에서 수행

자주 묻는 질문

내 JSON이 서버로 업로드되나요?

아니요. 파싱과 포맷은 브라우저 탭의 JavaScript로 실행되므로 데이터가 기기를 떠나지 않습니다.

기록은 어디에 저장되고 어떻게 지우나요?

'최근 5개 문서는 이 브라우저의 localStorage에 저장됩니다. 기록 카드에서 하나씩 삭제하거나 한 번에 모두 지울 수 있습니다.

주석이나 뒤에 붙은 쉼표를 지원하나요?

'지원하지 않습니다. 표준 JSON 파서를 사용하므로 주석, 뒤에 붙은 쉼표, 작은따옴표를 먼저 제거해야 합니다. 오류 위치가 어디를 볼지 알려 줍니다.

키를 정렬하면 데이터가 바뀌나요?

'출력 순서만 바뀌고 값은 그대로입니다. 정렬은 포맷 결과에만 적용되며 배열 순서는 절대 바뀌지 않습니다.

Base64 인코딩 / 디코딩

텍스트를 Base64로 인코딩하고 디코딩합니다. UTF-8 안전 모드를 지원합니다.

타임스탬프 변환기

'Unix 타임스탬프와 사람이 읽는 날짜를 서로 변환하고, 실시간 시계·시간대·시간 계산·코드 스니펫을 함께 제공합니다.

URL 인코딩 / 디코딩

URL 퍼센트 인코딩 및 디코딩, 컴포넌트 모드, 전체 URI 모드 및 URL 구조 분석.
