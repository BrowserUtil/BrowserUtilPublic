텍스트 비교

'두 텍스트를 줄 단위로 비교해 추가·삭제·변경된 부분을 모두 강조 표시합니다. 전부 브라우저에서 실행됩니다.

+0 추가됨-0 삭제됨~0 변경됨유사도 100%

0줄 · 0자

0줄 · 0자

양쪽에 텍스트를 입력하면 차이를 볼 수 있습니다.

사용 방법

  1. 1 왼쪽에 원본 텍스트, 오른쪽에 수정된 텍스트를 붙여넣으세요.
  2. 2 서식이 중요하지 않다면 대소문자 무시나 공백 무시를 켜세요.
  3. 3 강조된 결과를 확인하세요. 초록은 추가, 빨강은 삭제, 호박색은 변경입니다.

주요 기능

  • 줄 번호를 맞춘 줄 단위 비교
  • 나란히 보기와 한 번에 보기
  • 변경된 줄 안에서 문자 단위 강조
  • 대소문자 무시·공백 무시·줄 앞뒤 공백 제거 옵션
  • 유사도와 추가·삭제·변경 개수
  • 모든 계산이 로컬에서 이루어지며 업로드되지 않습니다

자주 묻는 질문

내 텍스트가 서버로 업로드되나요?

아니요. 비교는 브라우저의 JavaScript로 전부 실행되므로 텍스트가 기기를 떠나지 않습니다.

유사도는 어떻게 계산되나요?

양쪽 전체 줄 수와 서로 같은 줄 수를 비교합니다. 따라서 두 텍스트가 같으면 100%입니다.

크기 제한이 있나요?

입력이 매우 크면 페이지 반응성을 위해 앞의 몇 천 줄만 사용합니다. 큰 파일은 나누어 처리하세요.

관련 도구

글자 수 세기

'문자 수, 단어 수, 줄 수, 문단 수, 문장 수와 읽는 시간을 실시간으로 집계합니다. 영어와 CJK 텍스트를 모두 지원합니다.

JSON 포맷터

'JSON을 보기 좋게 정렬하고 압축·검증하며 오류 위치를 정확히 알려 줍니다. 접을 수 있는 트리 보기와 최근 5개 문서의 로컬 기록도 제공합니다.

Base64 인코딩 / 디코딩

텍스트를 Base64로 인코딩하고 디코딩합니다. UTF-8 안전 모드를 지원합니다.

BrowserUtil 소개

'개발자와 일상 업무를 위한 무료 온라인 도구 모음입니다. 모든 도구가 브라우저에서 로컬로 실행됩니다.
