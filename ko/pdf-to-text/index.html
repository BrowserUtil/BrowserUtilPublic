PDF 텍스트 추출

브라우저에서 PDF 문서의 텍스트를 로컬로 추출합니다. 페이지 범위 선택, 서식 정리, 글자 수 집계 및 TXT 파일 내보내기 지원.

PDF 파일 선택 또는 드래그 앤 드롭

로컬 .pdf 파일을 여기에 끌어다 놓거나 클릭하여 선택하세요. 브라우저에서 100% 로컬 처리됩니다.

추출 결과

문자 수: 0단어 수: 0줄 수: 0예상 읽기 시간: —
100% 로컬 실행: 브라우저 내부에서만 처리되며 데이터가 외부로 전송되지 않습니다.
오픈소스 프로젝트 기반:Mozilla pdf.jsApache-2.0&Tesseract.jsApache-2.0
100% 브라우저 로컬 실행 · 개인정보 보호

사용 방법

  1. 1 로컬 PDF 파일을 선택하거나 끌어다 놓으세요. '샘플 불러오기'로 즉시 테스트할 수도 있습니다.
  2. 2 전체 페이지 또는 원하는 페이지 범위를 지정하고 서식 옵션을 설정하세요.
  3. 3 '텍스트 추출'을 클릭하여 결과를 확인하고, 텍스트를 복사하거나 .txt 파일로 다운로드하세요.

주요 기능

  • Mozilla pdf.js 기반 100% 브라우저 로컬 텍스트 추출
  • 전체 페이지 또는 유연한 사용자 지정 페이지 범위 지원 (예: 1-3, 5)
  • 줄 바꿈 유지, 문단 병합, 공백 정리 등 깔끔한 서식 옵션
  • 실시간 글자·단어 수 통계 및 원클릭 .txt 다운로드

자주 묻는 질문

내 PDF 파일이 서버로 업로드되나요?

전혀 업로드되지 않습니다! BrowserUtil은 Mozilla pdf.js를 브라우저 탭 안에서 직접 실행하므로 파일이 서버로 전송되지 않습니다.

스캔된 PDF에서 텍스트가 추출되지 않는 이유는 무엇인가요?

일반적인 PDF 파서는 내장된 텍스트 레이어를 추출합니다. 텍스트 레이어가 없는 스캔 이미지나 사진 PDF의 경우 텍스트를 감지할 수 없으므로 OCR 도구가 필요합니다.

파일 크기나 페이지 수 제한이 있나요?

모든 처리가 로컬 기기에서 이루어지므로 파일 크기 제한은 컴퓨터의 메모리에 따릅니다. 수백 페이지에 달하는 문서도 원활하게 처리할 수 있습니다.

줄 바꿈을 유지하거나 병합할 수 있나요?

네! '줄 바꿈 유지' 옵션으로 원본 배치를 유지하거나, '단락 병합'으로 자연스러운 문단 흐름으로 정돈할 수 있습니다.

이 도구는 어떤 오픈소스 라이브러리를 사용하며 라이선스는 무엇인가요?

이 도구는 벡터 텍스트 추출을 위해 Mozilla pdf.js(Apache-2.0 라이선스)를 사용하고, WebAssembly 이미지 OCR을 위해 Tesseract.js(Apache-2.0 라이선스)를 사용합니다. 두 라이브러리 모두 브라우저 내부에서 100% 로컬로 안전하게 실행됩니다.
