비밀번호 생성기

강력한 무작위 비밀번호, 기억하기 쉬운 패스프레이즈 및 PIN 번호를 로컬에서 안전하게 생성.

보안 강도: 매우 약함0 bits · 예상 해독 시간: < 1s
16

사용 방법

  1. 1 생성 모드를 선택하세요: 무작위 문자, 기억하기 쉬운 패스프레이즈, 또는 숫자 PIN.
  2. 2 길이 및 문자 옵션(대소문자, 숫자, 기호 또는 단어 수)을 원하는 대로 설정하세요.
  3. 3 생성 버튼을 눌러 비밀번호를 만들고 실시간 엔트로피 점수를 확인하세요.
  4. 4 클릭 한 번으로 비밀번호를 복사하거나 일괄 생성으로 여러 개를 동시에 만드세요.

주요 기능

  • Web Crypto API를 사용한 암호학적으로 안전한 난수 생성
  • 3가지 생성 모드: 사용자 정의 무작위 비밀번호, 가독성 높은 패스프레이즈, 금융용 PIN
  • 실시간 섀넌 엔트로피(Entropy) 계산 및 무차별 대입 해독 시간 추정
  • 혼동하기 쉬운 문자(1과 l, 0과 O 등) 제외 기능
  • 한 번에 여러 비밀번호를 생성하고 모두 복사할 수 있는 일괄 모드
  • 현재 브라우저 탭 세션 메모리 기록(디스크 미저장)
  • 100% 브라우저 로컬 작동 — 생성된 비밀번호가 기기를 떠나지 않음

자주 묻는 질문

브라우저에서 생성한 비밀번호는 안전한가요?

매우 안전합니다. BrowserUtil은 단순 Math.random() 대신 운영체제의 암호화 난수 풀을 사용하는 window.crypto.getRandomValues()를 적용하여 생성합니다.

패스프레이즈(Passphrase)의 장점은 무엇인가요?

패스프레이즈는 무작위 단어 여러 개를 조합하여 만듭니다(예: crystal-river-brave-falcon). 높은 암호학적 엔트로피를 가지면서도 사람이 기억하고 모바일에서 직접 입력하기 쉽습니다.

생성된 비밀번호가 서버에 기록되나요?

전혀 기록되지 않습니다. 모든 연산은 브라우저 탭 내에서만 수행되며 네트워크 전송이나 서버 저장이 일절 일어나지 않습니다.
